# AI Tech Briefing PRD

## 1. 产品定位

AI Tech Briefing 是一个面向开发者的 AI 技术情报助手。

用户订阅自己关注的技术信息源，系统定时抓取内容，通过 AI 自动总结，并生成按时间排序的每日技术简报。

## 2. 目标用户

- 开发者
- 独立开发者
- 技术团队
- 技术管理者

## 3. 核心价值

- 减少用户手动浏览多个技术信息源的时间成本
- 聚合 RSS、官方博客、GitHub Release、Hacker News 等信息
- 使用 AI 提炼重点，降低阅读负担
- 提供中文摘要，方便快速理解英文技术内容
- 支持收藏和搜索，方便后续回顾

## 4. MVP 范围

### 4.1 用户系统

- 注册账号
- 登录账号
- GitHub OAuth 登录
- 查看和更新基础用户资料

基础用户资料字段：

- 昵称
- 邮箱
- 头像
- GitHub 账号信息
- 创建时间

### 4.2 RSS 订阅管理

用户可以：

- 添加 RSS Feed URL
- 删除 RSS Feed
- 修改 RSS Feed 名称
- 为 RSS Feed 设置分类
- 查看自己的 RSS Feed 列表

分类示例：

- Frontend
- AI
- Cloud
- Photography

### 4.3 内容抓取

系统每小时执行一次定时任务。

抓取内容包括：

- RSS Feed
- 标题
- 原文链接
- 正文或摘要内容
- 发布时间
- 来源名称
- 来源 URL

去重规则：

- 优先使用文章原文 URL
- URL 不可靠时，可结合标题、来源、发布时间生成唯一标识

### 4.4 AI 摘要

每篇新文章抓取后，系统自动生成：

- 三句话摘要
- 核心观点
- 关键词
- 中文翻译标题

AI 摘要结果需要存入数据库，避免重复生成。

### 4.5 Briefing 页面

用户登录后可以查看每日技术简报。

文章卡片展示：

- 原始标题
- 中文标题
- 来源
- 发布时间
- AI 摘要
- 关键词
- 原文链接
- 收藏按钮

### 4.6 收藏功能

用户可以：

- 收藏文章
- 取消收藏文章
- 查看收藏列表

收藏是用户维度的数据。同一篇文章可以被多个用户收藏。

### 4.7 搜索功能

支持搜索：

- 标题
- AI 摘要
- 来源名称

MVP 搜索方式：

- PostgreSQL 基础文本搜索或 `ILIKE`
- 支持分页
- 支持按发布时间排序

## 5. 非 MVP 范围

以下功能只保留设计方案，不在 MVP 开发：

- AI 问答
- 邮件日报
- AI 趋势分析
- 向量搜索
- pgvector 语义检索

## 6. 用户流程

### 新用户流程

1. 用户访问登录页
2. 使用邮箱注册或 GitHub OAuth 登录
3. 进入 Dashboard
4. 添加 RSS Feed
5. 等待系统抓取和总结
6. 查看 Briefing

### 日常使用流程

1. 用户登录
2. 进入 Dashboard
3. 查看最新技术简报
4. 搜索感兴趣内容
5. 收藏重要文章
6. 在 Bookmarks 页面回看收藏

## 7. 页面需求

- Login：邮箱登录、GitHub OAuth 登录、注册入口
- Dashboard：最新 Briefing、搜索、分页、收藏
- Feed Management：Feed 列表、添加 Feed、删除 Feed、分类管理
- Article Detail：文章详情、AI 摘要、关键词、原文链接、收藏
- Bookmarks：收藏列表、取消收藏、搜索
- Settings：用户资料、账号信息、GitHub 绑定状态

## 8. 权限规则

- 未登录用户只能访问登录 / 注册页面
- 登录用户只能管理自己的 Feed、分类和收藏
- 文章内容可以全局复用
- 收藏、Feed、分类必须绑定用户
- Cron 抓取接口必须受保护，避免公开调用

## 9. 成功指标

- 用户能成功注册 / 登录
- 用户能成功添加 RSS
- Cron 能稳定抓取文章
- 文章能正确去重
- AI 摘要能稳定生成
- Dashboard 能展示最新内容
- 搜索和收藏可用
